This repo contains two separate projects that uses Unity 6000.0.81f and .NET 10 Maui respectively. 
The Unity Project is a basic AR functionality project for Android devices. Users are able to open an AR camera and place cubes on a horizontal plane.
The Maui Project is a basic sample where if the user press teh Click Count button they are able to open an AR Scene that was exported from Unity.

In the Unity Project, in the Builds Folder, there is a example of the AR apk working.
